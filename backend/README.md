# MentorMatch AI

Hackathon-ready AI-matched alumni-student mentorship platform.

## Features
- Student onboarding
- Alumni profiles
- Explainable compatibility matching
- Mentor request workflow
- AI-style career roadmap
- Responsive dashboard
- FastAPI backend + React/Vite frontend

## Important
The matching engine in this MVP is deterministic and explainable. It can later be upgraded to embeddings/LLM matching without changing the product flow.
